ЧАСТЬ II. КОРПУС АСАН В «ШАРНГХАДХАРА-ПАДДХАТИ»

Ш́āрн̇гадхара-паддхати · главы 157–158 · раздел хатха-йоги · девять стихов об āсанах

Раздел хатха-йоги в «Ш́āрн̇гадхара-паддхати» подразделяется на две самостоятельные традиции: 1. Глава 157 (стихи 4372–4419): Шестичленная хатха-йога Горакши (Gorakṣādisusādhitaḥ prathamo haṭhayogaḥ); 2. Глава 158 (стихи 4420–4448): Восьмичленная хатха-йога Мāркан̣д̣еи (Mārkaṇḍeyādisādhito dvitīyo haṭhayogaḥ).

Ниже представлены все стихи, содержащие наставления и описания āсан, с текстологическими исправлениями наборных ошибок издания Питерсона 1888 года по манускриптам и текстам-первоисточникам.

РАЗДЕЛ А. ШЕСТИЧЛЕННАЯ ЙОГА ГОРАКШИ (ГЛАВА 157)

1. Стих 4375: Подготовка места и сиденья (Āsana-vidhi)

4375

एकान्ते विजने देशे पवित्रे निरुपद्रवे ।कम्बलाजिनवस्त्राणामु पर्य्यासनमभ्यसेत् ॥ ४३७५ ॥

ekānte vijane deśe pavitre nirupadrave /kambalājinavastrāṇām upary āsanam abhyaset // 4375 //

екāнте виджане деш́е павитре нирупадраве /камбалāджинавастрāн̣āм упарй āсанам абхйасет // 4375 //

Размер: Анушт̣убх (Anuṣṭubh)

Буквальный перевод

«В уединённом, безлюдном, чистом и безопасном месте поверх шерстяного одеяла, шкуры антилопы и ткани пусть практикует сиденье».

Литературный перевод

«В уединённом, безлюдном, чистом и безопасном месте следует практиковать āсану поверх сиденья, составленного из шерстяного покрывала, шкуры и ткани».

РАЗДЕЛ Б. ВОСЬМИЧЛЕННАЯ ЙОГА МАРКАНДЕИ (ГЛАВА 158)

4. Стихи 4428–4430: Общие правила практики и устройство сиденья

4428–4430

nādhyātaḥ kṣudhitaḥ śrānto na ca vyākulacetanaḥ /yuñjīta yogaṃ yogajño nityaṃ siddhy-artham ādṛtaḥ // 4428 //na śīte nāti caivoṣṇe na durdhe nāmbu-saṃnidhau /na sopadrava-deśeṣu yogaṃ saṃsādhayet kvacit // 4429 //ekānte vijane ramye pavitre nirupadrave /sukhāsane samādhiḥ syāt kuśājinacelottare // 4430 //

нāдхйāтах̣ кшудхитах̣ ш́рāнто на ча вйāкулачетанах̣ /йун̃джӣта йогам̣ йогаджн̃о нитйам̣ сиддхй-артхам āдр̣тах̣ // 4428 //на ш́ӣте нāти чаивошн̣е на дурдхе нāмбу-сам̣нидхау /на сопадрава-деш́ешу йогам̣ сам̣сāдхайет квачит // 4429 //екāнте виджане рамйе павитре нирупадраве /сукхāсане самāдхих̣ сйāт куш́āджиначелоттаре // 4430 //

Размер: Анушт̣убх (Anuṣṭubh)

Литературный перевод

«Знающий йогу не должен практиковать, будучи подавленным заботами, голодным, утомлённым или с смятенным умом; ради достижения успеха он должен приступать к практике с должным усердием (4428). Ни на холоде, ни при чрезмерном зное, ни при дурной погоде, ни близ шумной воды, ни в опасных местах йогу практиковать не следует никогда (4429). В уединённом, безлюдном, приятном, чистом и безопасном месте сосредоточение (самāдхи) достигается на удобном сиденье, уложенном слоями: трава куша, шкура антилопы и ткань поверх (4430)».

5. Стих 4431: Перечисление трёх ключевых āсан

4431

पद्ममर्धासनं चापि तथा सिद्धासनादिकम् ।आस्थाय योगं युञ्जीत कृत्वा च प्रणवं हृदि ॥ ४४३१ ॥

padmam ardhāsanaṃ cāpi tathā siddhāsanādikam /āsthāya yogaṃ yuñjīta kṛtvā ca praṇavaṃ hṛdi // 4431 //

падмам ардхāсанам̣ чāпи татхā сиддхāсанāдикам /āстхāйа йогам̣ йун̃джӣта кр̣твā ча пран̣авам̣ хр̣ди // 4431 //

Размер: Анушт̣убх (Anuṣṭubh)

В издании Питерсона 1888 г. допущена наборная опечатка padmam adhāsanaṃ. Правильное чтение ardhāsanaṃ («полулотос») надёжно восстанавливается по контексту стиха 4436, где описывается именно полулотос, и чтению манускриптов.

6. Стихи 4432–4434: Биомеханика сидячей позы

4432–4434

samaḥ samāsano bhūtvā saṃhṛtya caraṇāv ubhau /saṃvṛtāsyaḥ tathā coraḥ samyag viṣṭabhya cāgrataḥ // 4432 //pārṣṇibhyāṃ liṅga-vṛṣaṇāv aspṛśann agrayataḥ sthitaḥ /kiñcid unnamitaś cirā dantair dantān na saṃspṛśet // 4433 //saṃpaśyen nāsikāgraṃ svaṃ diśaś cānavalokayan /kuryād dṛḍhaṃ pṛṣṭhavaṃśaṃ coḍḍīyānaṃ tathodare // 4434 //

самах̣ самāсано бхӯтвā сам̣хр̣тйа чаран̣āв убхау /сам̣вр̣тāсйах̣ татхā чорах̣ самйаг вишт̣абхйа чāгратах̣ // 4432 //пāршн̣ибхйāм̣ лин̇га-вр̣шан̣āв аспр̣ш́анн аграйатах̣ стхитах̣ /кин̃чид уннамиташ́ чирā дантаир дантāн на сам̣спр̣ш́ет // 4433 //сам̣паш́йен нāсикāграм̣ свам̣ диш́аш́ чāнавалокайан /курйāд др̣д̣хам̣ пр̣шт̣хавам̣ш́ам̣ чод̣д̣ӣйāнам̣ татходаре // 4434 //

Размер: Анушт̣убх (Anuṣṭubh)

Литературный перевод

«Выровнявшись и устроив ровное сиденье, подобрав обе стопы, закрыв рот и подав грудь вперёд (4432); удерживая равновесие так, чтобы пятками не сдавливать половые органы; слегка приподняв подбородок и не сжимая зубы (4433); глядя на кончик своего носа и не озираясь по сторонам, следует держать позвоночник прямым и твёрдым (dṛḍhaṃ pṛṣṭhavaṃśam), а в области живота выполнять уд̣д̣ӣйāну (4434)».
